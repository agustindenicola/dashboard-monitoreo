# Dashboard de monitoreo operativo

Tablero web para que un cliente siga en un solo lugar sus operaciones: eventos detectados, riesgo por área, tendencia diaria por severidad, alertas recientes, informes generados y ahorro estimado.

> Caso real de DGLab, **anonimizado**: sin datos ni nombres de la empresa o sus clientes.

## Tecnología

HTML y CSS estáticos, sin dependencias. Para verlo, abrir `index.html` en el navegador.
